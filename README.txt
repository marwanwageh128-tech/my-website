MARWAN WAGEH PORTFOLIO WEBSITE
==============================

Open index.html in your browser to preview the website.
This is a static multi-page website (HTML, CSS, JavaScript) and can be hosted on GitHub Pages, Netlify or any standard web host.

PAGES
- index.html: Home / About
- apparel.html: Apparel & T-Shirt Graphics
- brand-identity.html: Brand Identity & Logo Design
- social-media.html: Social Media Design
- marketing.html: Printing
- contact.html: Contact page

IMPORTANT CUSTOMIZATION
1. Open contact.html and replace:
   - 201000000000 with your WhatsApp number including country code (Egypt: 20, without +).
   - yourusername in the Instagram and Facebook links with your actual usernames/page links.
2. Replace the visual placeholder cards in each category page with your actual portfolio images.
3. Add project images inside assets/projects/<category>/.
4. Edit each category HTML file to replace the placeholder artwork blocks with <img> elements if desired.

The website includes responsive navigation, mobile layout, scroll reveal effects, and a WhatsApp contact form.
