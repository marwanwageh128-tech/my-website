MEEZA DELIVERY — BRANDING PROJECT
This folder contains the six optimized artwork images and the project gallery page.
The gallery is a swipeable horizontal carousel on desktop and mobile.
To add more artwork to this project:
1. Add an optimized .webp image to this folder.
2. Add another <a class="detail-image"> item inside the .detail-gallery in index.html.
3. The carousel navigation and slide indicators are initialized automatically by assets/main.js.
